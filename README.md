# 番茄时钟与待办

一个本地运行的个人专注与任务管理工具。当前版本以“龙场静修”为视觉主题，将番茄钟、今日安排、待办分层管理、每日反思和周总结整合在同一个轻量工作台中。

![应用首页](src/assets/longchang-awakening-hero.png)

> 数据仅保存在浏览器 `localStorage`，无需账号，也不会上传至服务器。

## 26_7_26 大版本更新

- **多页面工作台**：首页、番茄钟、待办事项、今日安排、未完成待办、已完成待办、周总结与灵感池形成清晰导航。
- **今日安排与番茄钟联动**：当天开始日期和截止日期均为当天的未完成待办会自动纳入；也可从未完成待办批量加入。番茄钟只从今日安排选择绑定任务。
- **更完整的待办体系**：支持短期/长期、未开始/进行中/已完成/归档、父子待办、开始与截止日期、紧急/重要标记和自定义类型标签。
- **防误操作标签管理**：类型标签显示使用数量；删除前需要在原位二次确认，删除后会同步移除任务上的关联标签。
- **柔和的番茄提醒**：使用柔和双音提示；默认页面内提醒与声音提醒，可选开启桌面通知；阶段完成时停在完成状态，支持手动进入下一阶段或自动开始下一阶段。
- **完成统计与周复盘**：已完成待办页提供全历史类型标签饼图；周总结按周一至周日汇总完成任务、完成番茄、实际专注时长、每日趋势，并保存每周复盘。
- **视觉与响应式升级**：统一纸本工作台视觉、语义化状态色、键盘焦点与 44px 操作区域；桌面和小屏均可使用。

## 核心功能

### 番茄钟

- 自定义专注、短休、长休和长休间隔预设。
- 选择今日安排中的任务后，成功完成的专注番茄会累计到该任务。
- 支持暂停、重置、跳过和临时番茄。
- 计时采用截止时间计算，浏览器后台或页面失焦后回到前台仍保持正确时间流速。

### 待办与今日安排

- 未完成待办支持筛选、日期状态提示、批量加入今日安排与子待办。
- 已完成待办按日期查看，可记录每日自我反思和累计番茄数。
- 今日安排会隐藏已完成和已归档任务；移除自动纳入的任务后，当天不会重复自动加入。
- 灵感池用于临时记录和标记可执行想法。

### 数据复盘

- 历史类型饼图按已完成任务统计；一个任务包含多个类型标签时会分别计入，未标记任务归入“未分类”。
- 周总结可切换上一周、下一周或回到本周，展示 7 日完成趋势与本周已完成任务。
- 周复盘会随输入自动保存到本地。

## 数据说明

应用保存一个版本化 JSON 对象到 `localStorage`。当前数据版本为 `3`，包含番茄预设、待办、类型标签、每日与每周复盘、灵感、番茄记录和按日期保存的今日安排配置。

旧版本数据加载时会自动补齐新字段；若本地数据损坏，应用会恢复默认数据并显示提示。
