# 番茄时钟与待办

当前软件版本：1.0.1

本地运行的个人专注与任务管理工具。应用以“龙场静修”为视觉主题，将番茄钟、每日时间安排、今日待办、长期任务打卡、灵感归档、完成统计、每日反思和周总结整合到一个桌面工作台中。

![应用首页](src/assets/longchang-awakening-hero.png)

> 数据仅保存在本地存储中，无需账户，不会上传到服务器。

## 快速安装（最短路径）

普通用户不需要 Node.js 和命令行，三步即可使用：

1. **下载**：[Windows 安装包（v1.0.1）](https://github.com/Dream-will-come-true-oneday/Tomato_todo_list/releases/download/v1.0.1/longchang-pomodoro-todo-setup-1.0.1.exe)（如下载受限，请到 [发布页](https://github.com/Dream-will-come-true-oneday/Tomato_todo_list/releases/tag/v1.0.1) 的 Assets 中下载）。
2. **安装**：双击安装包，按向导完成。若 Windows 弹出安全提示，选择“更多信息 > 仍要运行”。
3. **打开**：从桌面快捷方式启动“番茄时钟与待办”即可使用。

补充说明：

- **升级**：应用内“设置 > 软件更新 > 检查更新”，确认后下载并“重启并安装”；也可直接运行新版安装包覆盖安装（数据保留）。
- **退出**：关闭窗口只是最小化到系统托盘，彻底退出需在托盘图标菜单中选择“退出”。
- **备份**：重装系统或换电脑前，请先“设置 > 数据管理 > 一键导出全部数据”。
- **迁移**：从浏览器版迁移数据见下文[浏览器迁移到桌面版](#浏览器迁移到桌面版)。

## 核心功能

- **番茄钟**：自定义专注/短休/长休预设，绑定今日安排任务自动累计番茄数；支持 Space 开始/暂停、R 重置、S 跳过；基于结束时间计算，切后台不漂移。
- **每日时间安排**：内置 19 项默认作息模板，按自然日循环提醒；支持编辑、新增、停用；Windows 桌面版关闭窗口后仍驻留托盘继续调度。
- **待办管理**：短期/长期、四状态流转、父子待办、日期与紧急重要标记、自定义类型标签；长期任务支持每日一次可撤销打卡。
- **今日安排**：当天开始的待办自动纳入，番茄钟只从今日安排中绑定任务。
- **灵感池**：独立标签分类，完成后按标签归档并支持 Markdown 记录，可重新打开。
- **统计与复盘**：完成类型饼图、周总结趋势、每日反思与周复盘，全部保存在本地。
- **撤销/重做**：破坏性操作后 8 秒内可点击撤销提示，或随时 Ctrl+Z / Ctrl+Shift+Z。
- **数据安全**：版本化本地存储（AppData v8），一键导出/导入全量备份，导入前强制先保存当前数据。

## 开发运行

```powershell
npm install
npm run dev        # 浏览器开发，访问 http://127.0.0.1:5173/
npm run desktop:dev  # Electron 桌面版开发
npm test           # 运行测试
npm run build:desktop  # 构建 Windows NSIS 安装包，产物在 release/
```

开发服务器固定端口 `5173`：端口被占用时会报错而不是自动切换，避免 `localStorage` 按端口隔离导致出现另一套空数据。

## 数据备份与恢复

1. 点击任意页面右上角齿轮“设置”，在“数据管理”中“一键导出全部数据”（建议保存到非系统盘、移动硬盘或云盘）。
2. 恢复时点击“从备份恢复”，选择 JSON 文件查看摘要；确认前系统会先要求保存当前数据备份。
3. 撤销记录只存在于当前会话内存，不计入备份；刷新、重启或导入备份后清空。

### 浏览器迁移到桌面版

浏览器和 Electron 使用独立本地存储，需手动迁移：在浏览器版“设置”中导出全部数据，再到桌面版“设置”中导入该 JSON 文件并确认替换。
