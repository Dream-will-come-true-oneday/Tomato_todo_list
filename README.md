# 番茄时钟与待办

本地运行的个人专注与任务管理工具。应用以“龙场静修”为视觉主题，将番茄钟、今日安排、父子待办、长期任务打卡、灵感归档、完成统计、每日反思和周总结整合到一个轻量工作台中。

![应用首页](src/assets/longchang-awakening-hero.png)

> 数据仅保存在浏览器 `localStorage`，无需账户，不会上传到服务器。请始终通过相同的本地地址访问应用，开发环境固定为 `http://127.0.0.1:5173/`。

## 本版本更新

- **长期任务每日打卡**：长期父任务与子任务可以每天独立打卡一次，并可撤销当天误操作；未完成页显示今日状态和累计次数，已完成页保留只读历史次数，不要求连续打卡。
- **灵感分类与完成归档**：灵感使用独立的自定义标签体系，完成前必须选择标签；已完成灵感进入独立页面，可按标签查看，并在详情小窗中编辑、预览 Markdown 完成记录。
- **灵感池喷泉反馈**：灵感池使用丘比特石雕喷泉实景图；新增灵感时播放发光信封入水与涟漪动画，完成灵感时显示水面亮光和星点反馈，并遵从减少动态效果设置。
- **番茄钟切页保留**：离开番茄钟页面时，运行中的计时会按真实截止时间结算后自动暂停；返回页面可继续当前阶段和剩余时间，且完成记录仍绑定启动时选择的待办。浏览器刷新仍会重置计时。
- **完成状态增强**：完成时间晚于截止时间的任务会显示“逾期完成”；完成类型占比升级为立体甜甜圈图，同时保留数量、百分比和文本图例。
- **数据模型升级**：数据版本升级至 `AppData v6`，迁移会保留旧待办、番茄记录、灵感和复盘数据，并补齐灵感标签、完成详情与长期任务打卡日期。
- **完成标签约束**：历史无有效类型标签的已完成待办会补充 `IT` 标签；后续未选择有效类型标签的待办不能标记为已完成。
- **更安全的标签管理**：删除标签前会进行行内确认；若删除会让已完成待办失去最后一个有效标签，系统会说明原因并阻止操作。
- **完成统计与周总结**：已完成待办页提供全历史类型标签饼图，只统计有效标签；周总结按周一至周日汇总完成待办、番茄、实际专注分钟数、每日趋势和周复盘。
- **周任务层级**：周总结会追溯完整父任务链，未完成父任务以“进行中”标记显示，不改变任务本身状态。
- **父子待办收纳**：未完成待办和已完成待办均支持父任务左侧展开/收起，以及当前列表的“全部展开 / 全部收起”。子任务采用稳定缩进、引导线和浅色层级背景，突出父子关系且不挤压日期、状态等列。
- **今日安排联动**：当天开始日期和截止日期均为当天的未完成待办会自动进入今日安排；也可从未完成待办批量加入。番茄钟只从今日安排中选择绑定任务。
- **番茄钟体验**：支持自定义专注、短休、长休预设，完成后显示柔和页面内提醒和可选声音提醒；支持手动或自动开始下一阶段。
- **工作台交互**：待办入口卡使用彩虹滚动边框作为悬浮与键盘焦点反馈，并遵从减少动态效果设置。
- **本地数据保护**：兼容旧数据缺失字段；读取失败时不再自动用默认数据覆盖原始 `localStorage`。开发服务器固定端口，避免端口变化造成另一套空存储。

## 核心功能

### 番茄钟

- 自定义专注、短休、长休和长休间隔预设。
- 绑定今日安排任务后，完成的专注番茄自动累计到该待办。
- 支持暂停、重置、跳过和临时番茄。
- 使用结束时间计算，浏览器切到后台或失焦后回到前台仍保持正确流速。

### 待办与今日安排

- 支持短期/长期、未开始/进行中/已完成/归档、开始与截止日期、紧急重要标记和自定义类型标签。
- 支持父子待办，父任务可单独或批量展开、收起子任务。
- 长期待办支持每日一次的可撤销打卡，父子任务分别累计，完成后保留历史次数。
- 未完成待办支持筛选、日期状态提示、创建子项和批量加入今日安排。
- 已完成待办按完成日期查看，显示累计番茄数、长期任务打卡次数和逾期完成状态，并支持每日自我反思。
- 今日安排会隐藏已完成和已归档任务；已移除的自动纳入任务当天不会再次自动加入。

### 灵感池

- 使用独立的自定义标签分类未完成灵感，未分类灵感可暂存但不能直接完成。
- 完成灵感按标签归档，可在详情小窗中记录 Markdown 格式的完成细节。
- 支持将已完成灵感重新打开，保留原标签和完成详情。
- 喷泉场景为新增和完成动作提供轻量视觉反馈，不影响数据保存与列表操作。

### 统计与复盘

- 历史类型饼图按已完成待办统计；多标签任务会分别计入对应类型。
- 周总结可切换上一周、下一周或回到本周，展示七日完成趋势和本周完成任务树。
- 每日反思和周复盘自动保存到本地。

## 快速开始

```powershell
npm install
npm run dev
```

启动后访问 `http://127.0.0.1:5173/`。端口被占用时，Vite 会明确报错而不是自动切换端口，以保护本地数据的访问一致性。

## 数据说明

应用将版本化 JSON 对象保存到 `localStorage`。当前数据版本为 `6`，包含番茄预设、待办、长期任务打卡日期、类型标签、每日与每周复盘、灵感标签与完成详情、番茄记录以及按日期保存的今日安排配置。

旧数据加载时会补齐新字段，并迁移历史已完成任务的类型标签和已完成灵感分类。浏览器的 `localStorage` 按协议、主机和端口隔离，因此请不要在 `5173` 与其他端口之间切换来访问同一份数据。
